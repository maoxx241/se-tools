# Joint Dev (`joint-dev` v2.0)

Flexible, manual-trigger (`/joint-dev`) multi-agent collaboration framework for Antigravity—capturing standing working agreements and model-strength routing without rigid state-machine ceremony:

- **Main Coordinator (`Antigravity` Main Chat)**: Keeps context clean; leads product UX, usability, interaction surface, and overall logic (`macro_brief.md`); decides technical details autonomously under design principles; reports **every 30 minutes + at major milestones**.
- **Subagents + `Codex Astra Max` (`effort="max"`)**: Deep technical implementation closure (`tech-closure`), systemic root-cause code review (`deep-review`), and optional direct authoring (`--mode author --write`) for math/theory-heavy low-LOC kernels.
- **`DSH` / `Grok` in Git Worktrees**: High-throughput implementation, dead-code subtraction, and test alignment (zero-watcher background run by default; optional `flash` `joint-coder-runner` for multi-wave / remote server test offload).
- **Anti-Defensive Gatekeeping (`<= 2` Review Rounds)**: Keeps systemic/root-cause & `P0`/`P1` fixes, upgrades symptom band-aids into structural fixes, and strips imaginary-enemy defensive programming.
- **Dedicated Strong-Model Documentation (`joint-docs-writer`)**: Exclusive owner of all `README`, `docs/`, `CONTRIBUTING`, guides, PR descriptions, and release notes—zero `Astra`/`dsh` prose.
- **End-to-End PR, CI & Merge Closure**: Once confirmed by the user, creates PRs, waits for CI checks to pass, squash-merges into `main`, fast-forwards local base checkouts, and cleans up temporary worktrees.
