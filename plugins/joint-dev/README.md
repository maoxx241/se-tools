# Joint Dev (`joint-dev` v2.1)

Flexible, manual-trigger (`/joint-dev`) multi-agent collaboration framework for Antigravity—built to accelerate **systemic architectural evolution** rather than locking agents into rigid file slices or parameter-tuning loops:

- **Main Coordinator (`Antigravity` Main Chat)**: Keeps context clean; owns product UX, interaction surface, and macro architecture (`macro_brief.md` as a **compaction-proof state anchor**); runs **bounded 30-minute heartbeats** (killed immediately on completion/pause) and never regresses into solo multi-file grinding after context compaction.
- **Empirical-First Systemic Evolution & Re-Entry**: Closes live hardware/benchmark/upstream ground truth before freezing final slices; treats file-ownership lists strictly as *same-wave merge-collision guards* (never permanent walls against refactoring legacy monoliths in the next wave); distills side-track breakthroughs via **`Delta Spec -> Astra Max Re-Closure -> Parallel Slices`**.
- **Cross-Platform `Codex Astra Max` (`gpt-6.2-astra` / `--model magpie`, `effort="max"`)**: Deep technical closure (`tech-closure`), mathematical counterexample proofs, systemic root-cause audit (`deep-review`), and optional math-kernel authoring (`--mode author --write`)—with automatic Windows `Win32 1385` sandbox avoidance and local-read verification.
- **`DSH` / `Grok` in Linked Git Worktrees + Anti-Spin Circuit Breaker**: High-throughput multi-file coding and dead-code subtraction (auto-discovers Windows `DeepSeek Harness` `dsh.cmd` and linked-worktree `.git` `commondir`); enforces a `<= 2`-attempt circuit breaker so no single subagent spins 1,000+ steps or exhausts `429` model quota.
- **Mandatory Anti-Defensive Gatekeeping (`joint-review-gatekeeper`, `<= 2` Rounds) & Late-Stage Documentation (`joint-docs-writer`)**: Audits systemic root causes and evaluation independence (e.g., `train` vs `heldout`, `L2` vs `L3`), strips imaginary-enemy defensive bloat, and writes all `README`/`docs/`/PR prose **after** code and metrics stabilize.
- **End-to-End PR, CI & Merge Closure**: Once confirmed by the user, creates PRs, watches CI to green, merges in topological order, fast-forwards local `main`, cleans up temporary worktrees, and tears down active timers.
